表格计算规则

N ≤ 8：ParallelGCThreads = max(1, N - 2)，主动为业务线程保留约 2 个核心。
N > 8：ParallelGCThreads = 8 + floor((N - 8) × 5 / 8)，采用 JVM 默认公式。
ConcGCThreads = max(1, floor((ParallelGCThreads + 3) / 4))

表格说明

  1. 推荐起始值基本为总堆的 25% 左右。这是 CMS + ParNew 下比较平衡的起点。
  2. 参数中 MaxTenuringThreshold=1，对象在年轻代只经历一次 GC 就晋升，因此年轻代不能太小，否则老年代会迅速被填满。
  3. 如果 GC 日志显示年轻代频率过高（例如每分钟超过 10~20 次），可以适当增大年轻代大小。
  4. 如果年轻代单次停顿过长（例如超过 30ms），可以适当减小年轻代大小。
